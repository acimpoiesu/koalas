# Description
Better Talos is to help inform Stuy students inform themselves on their classes (e.g. course rigor, course requirements, teacher evaluation, etc) and engage in public forums to discuss all things Stuy. Users can login and register accounts. Users can navigate to pages for certain classes which include details like the teacher(s), course description, and user submitted anecdotes on the class.
